그림과 글을 넣는 것부터 저장본 구분, 책으로 보기, 인쇄 준비까지 화면에 보이는 말 그대로 설명합니다.

1

처음 시작

만들 책을 골라 주세요

책 만들기 첫 화면에서 컬러링북 또는 그림책을 선택합니다.

컬러링북

그림을 넣고 페이지를 정리해 색칠책으로 인쇄할 때 사용합니다.

그림책

한 페이지에 그림과 글을 함께 넣고 이야기를 만들 때 사용합니다.

쉬운 방법 처음에는 그림책에서 글 넣기와 그림 넣기 두 버튼만 사용해도 충분합니다.
2

글과 그림

페이지에 내용을 넣고 움직여 보세요

  1. 페이지 선택왼쪽 페이지 목록에서 꾸밀 페이지를 누릅니다.
  2. 내용 넣기글 넣기 또는 그림 넣기를 누릅니다.
  3. 위치 옮기기페이지의 글이나 그림을 누른 채 원하는 곳으로 움직입니다.
  4. 크기 바꾸기오른쪽 선택한 내용에서 너비와 높이를 움직입니다.
글꼴크기 − 22 +굵게기울임밑줄글자색가운데

편집 화면에는 왼쪽과 오른쪽 페이지가 함께 보입니다. 먼저 편집할 쪽을 누른 뒤 글이나 그림을 넣으세요. 선택한 쪽은 초록색 테두리로 표시됩니다.

컬러링북은 왼쪽 글·오른쪽 그림, 그림책은 왼쪽 그림·오른쪽 글이 기본입니다. 그림과 글 자리 바꾸기를 누르면 펼침의 두 페이지가 서로 바뀝니다.

글을 선택하면 한글 문서처럼 글꼴, 크기, 굵게, 기울임, 밑줄, 글자색과 정렬 도구가 나타납니다.

펼침 관리

새 펼침 추가왼쪽과 오른쪽 본문 페이지를 한꺼번에 추가합니다.
앞 펼침·뒤 펼침좌우 두 페이지를 한 쌍으로 움직여 읽는 순서를 바꿉니다.
펼침 복제현재 왼쪽과 오른쪽 페이지를 함께 복제합니다.
펼침 삭제현재 좌우 페이지를 함께 지웁니다. 표지와 마지막 본문 펼침은 지울 수 없습니다.
3

저장과 저장본

현재 작업과 중요한 순간을 따로 보관해요

현재 자동 저장은 이 기기에만 저장됩니다. 서버 저장이 연결되기 전에는 중요한 책을 책 파일 받기로 보관해 주세요.
작업 중→학생 제출본→선생님 수정본→최종본

각 저장본은 별도로 만들어지므로 선생님이 수정해도 학생 제출본은 바뀌지 않습니다.

현재 상태 보관지금 작업을 따로 남깁니다.
학생 제출본학생이 제출한 순간의 책입니다.
선생님 수정 시작학생 제출본을 보존하고 새 수정본을 만듭니다.
이어서 만들기선택한 저장본을 바탕으로 새 작업을 시작합니다.
4

책으로 보기

독자가 보는 순서대로 넘겨 보세요

화면 위의 책으로 보기를 누르면 앞표지부터 뒤표지까지 플립북으로 확인할 수 있습니다. 이전과 다음 버튼 또는 키보드 방향키로 페이지를 넘깁니다.

기본 펼침 컬러링북은 왼쪽 글·오른쪽 그림, 그림책은 왼쪽 그림·오른쪽 글로 보입니다. 앞표지와 뒤표지는 한 장으로 표시됩니다.
5

인쇄 준비

용지와 인쇄 방법을 고릅니다

A4일반 프린터에서 가장 많이 사용하는 크기
B4복사기 B4와 ISO B4의 크기가 다르므로 규격 확인
A3큰 책이나 A4 크기의 소책자를 만들 때 사용

양면 위치 맞추기

  1. 1양면 위치 테스트를 누릅니다.
  2. 2인쇄 배율을 100% 또는 실제 크기로 선택합니다.
  3. 3인쇄물을 빛에 비춰 앞면과 뒷면 중심선 차이를 mm로 잽니다.
  4. 4앞면·뒷면 좌우와 상하 보정칸에 값을 입력합니다.
  5. 5프린터 설정 이름을 적고 저장합니다.

종이 두께는 소책자를 접었을 때 안쪽 페이지가 밀리는 정도를 보정하는 데 사용합니다. 평량이 같아도 실제 두께는 다를 수 있으므로 실물 테스트가 필요합니다.

6

수업에서 사용

회원·수업 기능은 계정 연결 후 제공됩니다

선생님 가입, 학급 만들기, 학생 초대와 실제 서버 제출은 KCSedutech·퍼즐로 계정 계약이 정해진 뒤 연결합니다.

현재 화면의 저장본 기능은 수업 흐름을 확인하기 위한 이 기기 보관 기능이며, 실제 선생님 권한을 판정하지 않습니다.
